电荷灵敏放大器的FET设计

阅读约 5 分钟 进阶
  • CSA
  • 电荷灵敏放大器
  • FET
  • 核电子学
本页目录 2 节
  1. 机制
  2. 误解与谣言

电荷灵敏放大器【以下简称CSA】是连接辐射探测器与后续信号处理电路的核心前端。理想情况下它可以将探测器输出的、携带能量与时间信息的微弱电荷脉冲，无失真地转换为一个幅度与总电荷量成正比的电压阶跃信号，同时尽可能不引入额外噪声。

CSA 的核心是一个带有电容负反馈的低噪声电压放大器。其工作原理基于“虚地”概念，实现了电荷到电压的线性转换。
其基本结构为一个高开环增益的放大器，其输出端与输入端之间跨接一个反馈电容 C f
当探测器产生的电荷 Q in 注入CSA输入端时，由于放大器增益极高，输入端近似为“虚地”。这迫使几乎全部电荷都转移到反馈电容 C f 上，使其充电。
根据电荷守恒，输出电压的变化量 Δ V out 近似为：

Δ V out ≈ − Q in C f

这个公式揭示了CSA最核心的特性：输出电压幅度仅由输入电荷量和反馈电容决定，而与探测器电容 C det 和输入端的杂散电容基本无关。这种对探测器电容变化的“免疫力”，是CSA被广泛采用的根本原因。
ENC（等效噪声电荷）是衡量CSA噪声性能的核心指标，其本质是将电路内部所有噪声源的影响，折算到输入端，等效为多少数量的电子电荷。ENC并非单一噪声，而是一个由串联噪声、并联噪声和1/f噪声三大基本成分构成的合成值。
CSA的设计充满了精密的权衡， C f 越小，增益越高。但高增益会限制动态范围。增大 C f 可扩大动态范围，但会降低转换增益，并可能恶化ENC。
输入级通常采用低噪声结型场效应晶体管（JFET），因为它具有高输入阻抗和优异的噪声性能。在高计数率或特殊环境（如高温）下，也会采用双极型晶体管或碳化硅JFET

在我消失的这些时间里我一直在围绕CSA做各种研究。

JFET设计

CSA的噪声性能并不是简单的输入电容越小越好，而是一个需要权衡的优化问题。对于JFET，ENC其大小与输入总电容成正比，与跨导的平方根成反比。总输入电容 C det +JFET的 C f +寄生电容越小，理论噪声越低，因为JFET的电压噪声会通过总电容转化为噪声电荷，电容越小，转化后的噪声电荷就越少。
但在现实中，JFET不是完美的。它的电压噪声和跨导 gm 密切相关： gm 越大（电压噪声越小），JFET的输入电容通常也越大。如果追求 C in 很小，就只能用小JFET，结果Gm小，ENC反而变大。需要在增大 gm 和减小 C in 之间找到最佳平衡点。

当探测器电容 C det 较大时，如果死用一个小 C in 的JFET，虽然总输入电容增加不多，但因为电压噪声太大，整体噪声反而更高，这时应该主动选择较大 C in 的JFET（或并联多个JFET），让JFET的输入电容 C in 接近 C det 此时大 gm 带来的噪声降低效果，能超过因 C in 增大而多出来的那部分噪声，最终ENC达到最低。

固定同一个JFET时： C det 越小，ENC越小。增大 C det 会直接让ENC增加。
可以调整JFET时：对于不同的 C det ,最佳噪声性能通常出现在 C in ≈ C det 附件。这就是为什么老资历工程师会强调大电容探测器要用大电容JFET。

关于JFET的工作电流，当 I D 接近 I DSS 时（Vgs≈0）：此时跨导 gm 确实是最大的。但是，在这个点工作非常危险：最大的问题是栅极电流噪声，当Vgs接近0V甚至微正时，JFET栅极PN结会产生显著漏电流，这会引入巨大的电流噪声。对于核探测器这种高阻抗探测器，电流噪声是致命的。其次是功耗失控，管子发热严重，热噪声随之飙升。
当 I D 取中间值时，虽然 gm 相比峰值下降了一点（大约降了20-30%），但此时栅极漏电流极小，且工作点远离截止区和饱和区，线性度最好，电压噪声和电流噪声的综合平衡点最高。
